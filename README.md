# Ayrık Yapılar Dersi - 3. Hafta Ödevi

Selamlar, yazılım mühendisliği 2. sınıf Ayrık Yapılar dersi için hazırladığım 3. hafta ödevini bu repoya ekliyorum. 

Ödev temel olarak ispat yöntemleri üzerineydi. Belgenin içinde şu konuların detaylı soru çözümleri var:
- Doğrudan İspat
- Karşıt Tersle İspat 
- Çelişki Bulma yöntemi
- Tümevarım ile ispat

Çözümlerin tamamını Word üzerinden tek tek düzenleyerek hazırladım. Özellikle ispat sorularında mantığı oturtmakta zorlanan veya "bu soruya nasıl başlarım" diye örnek arayan arkadaşların işine yarayabilir.
